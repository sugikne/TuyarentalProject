# TuyaRental Nusa Penida

TuyaRental Nusa Penida adalah platform website penyewaan kendaraan dan layanan wisata yang dirancang untuk memudahkan wisatawan dalam mencari, memesan, dan mengelola layanan rental di Nusa Penida secara online.

Website ini dibuat dengan tampilan modern, responsif, dan user-friendly sehingga memudahkan pelanggan untuk melihat daftar kendaraan, harga rental, paket wisata, galeri, serta melakukan reservasi dengan cepat.

## Fitur Utama

* Dashboard admin untuk mengelola konten website
* CRUD data kendaraan dan paket wisata
* Upload dan manajemen galeri foto
* Pengelolaan testimoni pelanggan
* Sistem update harga rental
* Tampilan responsif untuk mobile dan desktop
* Integrasi database untuk penyimpanan data
* UI modern dan mudah digunakan

## Tujuan Project

Project ini dibuat untuk membantu digitalisasi bisnis rental dan tour di Nusa Penida agar lebih profesional, mudah diakses pelanggan, dan meningkatkan efisiensi pengelolaan layanan secara online.

## Teknologi yang Digunakan

* React / Next.js
* Tailwind CSS
* Node.js
* Database Integration
* REST API
* Modern Responsive UI
